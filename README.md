# votario Camera — downloads

This repository only hosts the release files of **votario Camera**, a small macOS menu-bar app
that shows a meeting card (green, yellow, red, ½ 1 2 3 5 8 13 ?) in your camera image in any
video app.

Information, installation steps and the current download: **https://votario.web.app/mac**

The DMGs are signed and notarized by Apple. Imprint, privacy and terms of use:
https://votario.web.app/imprint
